# Vidéos

Emplacement de la vidéo du hero.

Déposez ici un fichier `hero.mp4` (H.264, ~8 s, muet, 1080p max, < 3 Mo),
puis renseignez son chemin sur la balise vidéo de la page d'accueil :

    <video ... data-src="assets/videos/hero.mp4">

Tant que l'attribut est vide, l'image `assets/images/hero-poster.svg`
reste affichée : aucun décalage de mise en page, aucun téléchargement inutile.
